# TODO 
This TODO app is a collaborative project developed using JavaScript, CSS, and HTML. It allows users to create, manage, and delete tasks efficiently, providing a simple and user-friendly interface for task management.

### About This Project
The TODO app was built as a team project to practice web development skills and enhance collaboration. The application offers essential functionalities for users to keep track of their tasks and improve productivity.

### Features
  - Add Tasks: Users can create new tasks easily.
  - Manage Tasks: Mark tasks as complete or delete them when no longer needed.
  - User-Friendly Interface: Designed with a clean layout for easy navigation.
### Technologies Used
  - Frontend: HTML, CSS, JavaScript.
  - Collaborative Tools: Git, Trello.
